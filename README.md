# ETH Radar — Крипто Пузырь

Мгновенный сигнал LONG/SHORT по ETH. PWA-приложение, устанавливается на
экран телефона. Полностью клиентский — считает всё в браузере, напрямую
дёргает публичный Binance REST API, бэкенд не нужен.

## Из чего собран сигнал

5 базовых блоков (Trend / Structure / Momentum / Flow / Liquidity) —
EMA-выравнивание по 15m/1h/4h, кластеризация pivot-уровней, ROC+RSI+
дивергенция, Open Interest + CVD-прокси + funding rate, дистанция до
ближайшей ликвидности.

Плюс 3 экспериментальных блока, перенесённых из разбора стороннего
индикатора (adaptive-length RSI, swing/pivot зоны, volume-weighted
momentum) — **но они не участвуют в скоре просто так**. При каждом
открытии приложение прогоняет `runExperimentalBacktest()` на последних
~500 часовых свечах Binance: сравнивает направленную точность простого
baseline (trend+momentum) отдельно и baseline+experimental отдельно на
горизонте 12ч. Экспериментальные блоки получают вес в итоговом скоре
только если на этом backtest'е они реально дают точность выше baseline
(при минимум 100 наблюдениях с каждой стороны). Если нет — они всё равно
показываются как чипы в интерфейсе (с пометкой "НЕ В ВЕСЕ"), но не влияют
на LONG/SHORT.

Все новые фичи causal-safe: pivot засчитывается только через несколько
баров после него (как это и будет в реальном времени), adaptive RSI
и volume-weighted momentum используют только прошлые/текущий бар —
проверено тестом, что добавление более поздних данных не меняет уже
посчитанные исторические значения (нет утечки будущего).

## Важная оговорка

Backtest внутри приложения — лёгкая, встроенная проверка на ~500 барах
(~20 дней), не замена полноценному walk-forward/holdout, который
используется в Python-версии ETH Radar (там ~9000 баров, честная
калибровка, untouched holdout, журнал прогнозов с сверкой факта). Здесь
это разумный компромисс для полностью статичного, бессерверного
приложения — лучше, чем зашитый на глаз вес, но не такой строгий тест,
как в бэкенде.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `eth-radar`)
2. Загрузи в него все файлы из этого архива (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) — прямо в корень репозитория
3. Зайди в **Settings → Pages**
4. В разделе **Source** выбери ветку `main` и папку `/ (root)` → **Save**
5. Через 1-2 минуты сайт появится по адресу:
   `https://ТВОЙ-НИК.github.io/eth-radar/`

## Установка на iPhone

1. Открой ссылку на сайт в **Safari** (обязательно Safari, не Chrome)
2. Нажми кнопку **"Поделиться"** внизу экрана
3. Выбери **"На экран Домой"**
4. Готово — иконка появится как обычное приложение
