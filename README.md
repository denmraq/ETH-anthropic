# ETH Radar — Крипто Пузырь

Мгновенный сигнал LONG/SHORT по ETH. PWA-приложение, устанавливается на
экран телефона. Полностью клиентский — считает всё в браузере, напрямую
дёргает публичный Binance REST API, бэкенд не нужен.

## Из чего собран сигнал

5 базовых блоков (Trend / Structure / Momentum / Flow / Liquidity) —
EMA-выравнивание по 15m/1h/4h, кластеризация pivot-уровней, ROC+RSI+
дивергенция, Open Interest + живой CVD/книга заявок/ликвидации через
публичные Binance WebSocket-стримы, дистанция до ближайшей ликвидности.

Плюс 3 экспериментальных блока (adaptive-length RSI, swing/pivot зоны,
volume-weighted momentum) — участвуют в скоре только если backtest на
последних ~500 часовых свечах (горизонт 12ч) реально показывает точность
выше baseline. Backtest теперь пересчитывается на каждом сканировании
(без кэша) — предыдущая версия кэшировала результат на 10 минут по
настенным часам, что на iOS PWA (где вкладка часто не перезагружается, а
"будится" из фона) могло выглядеть как зависшее число.

## Как выложить на GitHub Pages

1. Загрузи index.html, manifest.json, sw.js, icon-192.png, icon-512.png в корень репозитория (замени существующие)
2. GitHub Pages подхватит изменения через 1-2 минуты

## Обновление на iPhone

Service worker версия кэша поднята (v8) — старая закэшированная копия
будет автоматически вытеснена при следующем открытии. Если не обновится
сразу — удали иконку с экрана Домой и переустанови через Safari
("Поделиться" → "На экран Домой").
