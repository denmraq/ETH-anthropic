# ETH RADAR — FINAL (Anthropic + GPT merged)

Объединённая рабочая ветка: взял более сильную по инженерии ML-часть
("GPT"-ветка: sigmoid/Platt-калибровка, honest holdout, стабилизатор
сигнала с гистерезисом и подтверждением на разных закрытых свечах) и
добавил обратно то, чего в ней не хватало по итогам разбора
("Anthropic"-ветка: автосверка прогнозов с фактической ценой, новости).

## Внутри
- OKX ETH-USDT-SWAP, live-цена отдельно от закрытой свечи признаков.
- 3 отдельные LightGBM модели: 1ч / 12ч / 24ч, target `Price(t+h) > Price(t)`.
- ~9000 закрытых 1H баров, реальный исторический funding через `merge_asof`.
- TimeSeriesSplit + embargo `gap=horizon`, untouched holdout (последние ~15%
  истории), отдельные accuracy/Brier/LONG precision/SHORT precision на holdout.
- Sigmoid/Platt-калибровка вероятностей (`ml/calibration.py`) — с
  автоматическим fallback на ручную реализацию, если в будущей версии
  scikit-learn (1.7+) уберут `cv="prefit"`. Больше не зависит от жёсткого
  пина версии.
- Expected-return бакеты только из walk-forward OOF, минимум 30 наблюдений.
- Trade tape (buy/sell notional) + orderbook OFI + microprice — маленький
  живой overlay только для 1ч, максимум ±5 п.п., никогда не выдаётся за
  обученный признак.
- Signal Stabilizer: гистерезис по горизонту (0.55/0.45 → 0.58/0.42 к 24ч) +
  2 подтверждения на РАЗНЫХ закрытых свечах для разворота направления.
  Состояние — на диске (`runtime/signal_state.json`), сервис жёстко
  запускается с `--workers 1`, чтобы состояние было единым.
- **Журнал прогнозов с автосверкой факта** (`ml/prediction_log.py`):
  каждый прогноз по каждому горизонту логируется, и при последующих
  вызовах `/api/v4/predict` автоматически сверяется с реальной ценой,
  когда наступает `target_time`. `/api/v4/validation` отдаёт живой,
  растущий winrate отдельно от бэктеста.
- Новости ETH (RSS + перевод на русский) — `/api/v4/news`, справочно,
  не участвуют в ML-сигнале.
- SL/TP/Kelly — отдельный risk heuristic, явно помечен как не-прогноз.
- 15-секундный кэш живых данных OKX.

## Что намеренно НЕ включено
- target `future_return > 1.5%` (нестабильно из-за дисбаланса классов);
- ручной 24ч EMA-сигнал без ML;
- OFI/microprice как обучаемые исторические признаки (нет честного
  исторического стакана);
- Binance Futures (Render отдаёт 451 в некоторых регионах).

## Первый запуск
При отсутствии `ml/eth_direction_lgbm.joblib` обучение стартует в фоне
автоматически. `/api/health` показывает статус (`model_training`,
`training_error` при сбое). После обучения активируются все 3 горизонта.

Если обновляетесь с более старой версии — удалите старый
`ml/eth_direction_lgbm.joblib` и `ml/walk_forward_report.json` перед
первым запуском (формат модели — словарь из трёх моделей, а не одна).

## Render / деплой
Загрузить весь комплект в корень GitHub-репозитория и запустить
Deploy latest commit. Процесс специально запускается с `--workers 1`
(см. `Procfile` и `start.sh`) — это обязательно, иначе стабилизатор
сигнала будет иметь разное состояние в разных воркерах.

## Эндпоинты
- `GET /api/health` — статус моделей и обучения.
- `GET /api/v4/predict` — прогноз по 1ч/12ч/24ч + риск-план + live-контекст.
- `GET /api/v4/validation` — walk-forward, holdout и живая сверенная точность.
- `GET /api/v4/news` — новости ETH на русском (справочно).
- `GET /api/v4/log/status` — статистика журнала прогнозов.

Важно: вероятностная модель и риск-план не гарантируют торговый результат
и не являются инвестиционной рекомендацией.
