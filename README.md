# ETH Radar — Крипто Пузырь

Мгновенный сигнал LONG/SHORT по ETH. PWA-приложение, устанавливается на экран телефона.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `eth-radar`)
2. Загрузи в него все файлы из этого архива (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) — прямо в корень репозитория
3. Зайди в **Settings → Pages**
4. В разделе **Source** выбери ветку `main` и папку `/ (root)` → **Save**
5. Через 1-2 минуты сайт появится по адресу:
   `https://ТВОЙ-НИК.github.io/eth-radar/`

## Установка на iPhone

1. Открой ссылку на сайт в **Safari** (обязательно Safari, не Chrome)
2. Нажми кнопку **"Поделиться"** внизу экрана
3. Выбери **"На экран Домой"**
4. Готово — иконка появится как обычное приложение
